# UR10e mesh attribution

`robot.glb` and `restocking_cell.glb` contain transformed UR10e visual mesh geometry from
Universal Robots' [`Universal_Robots_ROS2_Description`](https://github.com/UniversalRobots/Universal_Robots_ROS2_Description),
release 3.5.1, distributed through the ROS 2 Jazzy `ur_description` package.

The upstream package identifies Universal Robots A/S as its maintainer and licenses these sources
under the BSD 3-Clause license. The upstream package's separate graphical-documentation terms apply
to other named robot models and not to the UR10e assets used here.
