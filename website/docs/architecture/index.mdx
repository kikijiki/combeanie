# Architecture Overview

How the software is put together once you already know the [Introduction](/docs)
(problem, scenario, robot, and workcell).

Classical planning and world state stay authoritative. Wrist perception and overhead depth
obstacles supply required evidence on the default path; the recovery reasoner is optional and
advisory. If ROS, Gazebo, or MoveIt are new to you, read [Fundamentals](/docs/fundamentals)
first.
